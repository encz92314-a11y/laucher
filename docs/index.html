常见问题

我需要先装 Java 吗？

Zephyr 会查找实例需要的 Java 版本。如果没找到，请按提示安装。Apple 芯片 Mac 需要 ARM64 Java。

三个预设会改变游戏分辨率吗？

不会。预设调整渲染距离、模拟距离等设置，并按版本选择优化模组。实际帧率取决于硬件和模组组合。

为什么 CurseForge 或 Microsoft 登录需要配置？

Modrinth 可以直接浏览。CurseForge 需要官方 API Key；Microsoft 在线登录需要 Minecraft Services 批准 Zephyr 的应用访问。离线昵称可用来玩本地单人游戏。

Mac 安装包已经完成 Apple 公证了吗？

当前 Mac 预览版已通过 ARM64 启动检查，尚未完成 Apple 公证。
